# Âmbito do projeto

Este repositório corresponde exclusivamente ao site **Gestão de Alojamentos by MontanhAoRedor**.

## Isolamento

- Não importa código do site Casa do Lagar.
- Não importa código do site Transfers & Tours.
- Usa uma cópia versionada dos tokens visuais MontanhAoRedor.
- As ligações entre sites são apenas URLs públicas.
- Alterações e publicações deste projeto não alteram os outros dois sites.

## Brand Kit

Versão incorporada: `1.0.0`, com verde-azeitona, creme, verde-água, cobre, Cormorant Garamond e DM Sans.
